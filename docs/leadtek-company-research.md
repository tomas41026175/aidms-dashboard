## 前端技術棧推測

- **框架**：Vue.js 或 React（GDMS/AIDMS 為 Web Dashboard）
- **元件庫**：Element UI 或 Ant Design（管理後台常見）
- **其他**：資料視覺化（Charts）、WebSocket 即時更新、REST API 整合
- 官網後端：ASP.NET，多語系支援（繁中 / 英 / 日 / 越南語）

---

## 面試準備建議

### 技術重點

1. React / Vue 深度問題（Lifecycle、狀態管理、效能優化）
2. Web Dashboard 開發經驗
3. 資料視覺化（Charts.js / D3.js / ECharts）
4. WebSocket / Polling 即時資料監控
5. 跨瀏覽器相容性（GDMS 支援 Chrome/Firefox/IE 10+）
6. TypeScript 基礎

### 作品集方向

- 管理後台 / Dashboard 類作品最加分
- AI 資料視覺化相關更佳
- 展示效能優化或即時資料處理的經驗

### 公司文化 Q&A

- 為何想在硬體公司的軟體部門發展？
- 對 AI 工具開發（AIDMS/GDMS）有興趣嗎？
